# Fieldwork design
Canvassers look at phones on residential sidewalks in bright daylight; the owner scans team activity on a desktop. Use a light, high-contrast interface. Brand: WE ROOF, requested by the owner.

Restrained warm neutral surfaces, charcoal navigation and deep ink text, and roofing red for primary actions. Map outcomes have dedicated semantic colors with labels and distinct symbols. Use system sans typography and tabular numbers for time. The desktop has a fixed compact navigation rail, a flexible map workspace, and a contextual team panel. Forms use inline drawers, 44px controls, clear validation and feedback. Native screens use the same labels and semantic colors. Motion only communicates state and respects reduced motion.
